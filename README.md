# mitesh-portfolio

Personal portfolio site for Mitesh Patel — Team Lead & Full Stack Developer
(Node.js, React/Angular, and the databases behind them).

Built with Create React App. Single-page site, content lives in
`src/App.js`, styling in `src/App.css`.

## Scripts

- `npm start` — run the dev server at http://localhost:3000
- `npm run build` — production build to `build/`
- `npm test` — run the test suite

## Content

Copy (About/Experience/Projects/Skills) is sourced from the author's CV
(`public/MiteshPatelCV.pdf`, also served as the downloadable resume). Update
`src/App.js` directly to change content — there's no CMS or data file.
